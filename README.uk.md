# FreeMon

Моніторинг доступності мережевих пристроїв для Windows і Linux: пінг і перевірки служб, мапа родин пристроїв,
історія та PDF-звіти, сповіщення на пошту й у месенджери. Безкоштовно, з відкритим кодом (MIT).

- **Інструкція користувача:** [docs/MANUAL.uk.md](docs/MANUAL.uk.md) (англійською: [docs/MANUAL.md](docs/MANUAL.md))
- **Збирання релізів і публікація:** [docs/RELEASING.uk.md](docs/RELEASING.uk.md) (англійською: [docs/RELEASING.md](docs/RELEASING.md))

## Що вміє FreeMon

### Моніторинг
- **Пінг (ICMP)** IPv4- та IPv6-адрес і імен хостів: інтервал, кількість і розмір пакетів, час очікування, пороги.
- **Стани:** Є зв'язок, Нестабільно (втрати або висока затримка), Немає зв'язку, Недоступний через батька, Вимкнено, Невідомо.
  Стан змінюється лише після N перевірок поспіль з новим результатом — короткі збої не дають хибних тривог.
- **Основна перевірка без пінгу** для пристроїв, що не відповідають на пінг: TCP-порт, HTTP(S)-запит, значення HTTP JSON або DNS-запит.
- **Додаткові перевірки** служб на будь-якому пристрої: TCP-порт, HTTP(S) (коди відповіді, очікуваний текст,
  самопідписані сертифікати), DNS (пристрій опитується як DNS-сервер), **HTTP JSON** — значення з JSON-відповіді
  порівнюється з умовами, наприклад стан датчика Home Assistant чи будь-яке REST API.
- **Параметри на трьох рівнях:** загальні → тип пристрою → пристрій.
- **Батьківські пристрої:** коли роутер недоступний, пристрої за ним — «Недоступний через батька» і не засипають сповіщеннями.

### Інтерфейс
- **Мапа** родин пристроїв (батько в центрі, діти навколо): перетягування позначок і карток родин,
  згортання родин, режим «лише проблемні», відкриття однієї родини окремо (⤢) з навігацією назад,
  рамки й підписи можна сховати.
- **Дерево** із затримкою, втратами, станом і його тривалістю; підказки з усіма подробицями.
- **Панель «Події»** знизу; останню подію можна показувати в рядку стану.
- **Для стіни:** стрілка зліва вгорі згортає все над мапою, лишаючи лічильники станів.
- **Правий клік по пристрою:** підключення SSH і веб (свій браузер і SSH-клієнт), трасування маршруту (MTR),
  історія, редагування.
- Світла й темна теми, значок у треї (відкрити / перезапустити / вийти), автозапуск, інтерфейс українською та англійською.

### Історія та звіти
- Історія пристрою за будь-який період: доступність, перерви, інциденти, графік затримки й втрат.
- **Перерви в моніторингу** (FreeMon не працював, моніторинг вимкнено) заштриховані на графіку, перелічені у звіті
  й не враховуються в доступності.
- **PDF-звіт** з підсумком звичайною мовою, графіком, інцидентами, перервами, місцем для підпису і кодом перевірки.
- **Сирий журнал (TXT)** усіх перевірок, включно з додатковими.
- Мова звітів може відрізнятися від мови інтерфейсу.

### Сповіщення
- Спливаюче вікно в куті екрана.
- **Власні звуки** для «Немає зв'язку», «Нестабільно» і тихий — для відновлення; вимикаються для окремого пристрою.
- **Канали:** email (SMTP) і вебхуки з шаблонами для Telegram, Virola, Node-RED, ntfy, Gotify, Mattermost / Slack.
  Фільтри для кожного каналу, вимикач для кожного пристрою, групування одночасних змін, повторні спроби.

### Безпека і дані
- **Режими доступу:** без обмежень; режим перегляду з режимом адміністратора за кнопкою; режим перегляду
  з паролем адміністратора. Автоблокування після бездіяльності.
- **Шифрування:** конфігурація і секрети каналів зашифровані, ключ прив'язаний до комп'ютера.
- **Цілісність:** журнал перевірок щогодини запечатується; з паролем адміністратора печатки ще й засвідчуються.
  Кожен звіт має код перевірки, який перевіряє сама програма.
- **Резервні копії:** вручну (з паролем) і автоматично за розкладом; відновлення в майстрі на новому комп'ютері.
- Імпорт та експорт списку пристроїв (CSV).

### Мережева політика
FreeMon з'єднується лише з адресами, які задали ви: пристрої моніторингу, DNS-сервер для імен хостів,
SMTP-сервер і адреси вебхуків. Без оновлень, телеметрії й завантажень. Докладно — «Про програму → Мережева політика».

## Вимоги
- Windows 10 / 11 x64 або x64-дистрибутив Linux, що підтримується .NET 10
  (Debian, Ubuntu, RHEL і сумісні, Fedora, openSUSE / SLES).
- Linux: пінг без root працює через ICMP-сокети (`net.ipv4.ping_group_range`), інакше використовується системний `ping`.
- Трасування маршруту — системними утилітами: `mtr` / `tracepath` / `traceroute` на Linux, `pathping` / `tracert` на Windows.

## Завантаження і встановлення
Релізи — на сторінці **Releases** цього репозиторію.

| Файл | Для чого |
| --- | --- |
| `freemon-<версія>-win-x64-setup.exe` | інсталятор Windows |
| `freemon-<версія>-win-x64-portable.zip` | портабельна Windows: розпакувати й запустити `freemon.exe` |
| `freemon_<версія>-1_amd64.deb` | Debian, Ubuntu: `sudo apt install ./freemon_<версія>-1_amd64.deb` |
| `freemon-<версія>-1.x86_64.rpm` | RHEL-сумісні, Fedora: `sudo dnf install ./freemon-…rpm`; openSUSE: `sudo zypper install ./freemon-…rpm` |
| `freemon-<версія>-linux-x64-portable.tar.gz` | будь-який x64 Linux: розпакувати й запустити `./freemon` |

Під час першого запуску майстер питає мови, де зберігати дані і режим доступу; там же можна відновити резервну копію.

## Де дані
| Варіант | Тека даних |
| --- | --- |
| Лише для мене | Windows: `%APPDATA%\FreeMon`; Linux: `~/.local/share/FreeMon` |
| Для всіх користувачів (Windows) | `C:\ProgramData\FreeMon` |
| Портабельно | `data` поруч із програмою |
| Своя тека | вибрана вами тека |

Персональні налаштування (мова інтерфейсу, браузер, SSH-клієнт, стан вікна) — у файлі `ui.json` у профілі
користувача (`%APPDATA%\FreeMon`, `~/.config/FreeMon`); у портабельному варіанті — у теці даних.

Дані зашифровані з прив'язкою до комп'ютера: **щоб перенести FreeMon на інший комп'ютер, використовуйте резервну копію** —
простого копіювання теки недостатньо. Робіть резервні копії регулярно.

## Збирання з вихідного коду
Потрібен .NET 10 SDK.
```
./build.sh              # збірки для Linux і Windows у dist/
./build.sh linux-x64    # лише Linux
build.cmd               # на Windows (додає іконку й версію в exe)
./release.sh <адреса>   # усі файли релізу: див. docs/RELEASING.uk.md
```
