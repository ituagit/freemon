# FreeMon — інструкція користувача

## 1. Перший запуск

Під час першого запуску відкривається майстер.

1. **Мова інтерфейсу** — перший рядок. Після вибору майстер одразу перемальовується.
2. **Мова звітів** (PDF, сирий журнал) — може відрізнятися від мови інтерфейсу.
3. **Відновити з резервної копії…** — якщо переносите FreeMon з іншого комп'ютера (див. розділ 10).
4. **Де зберігати дані:**
   - **Лише для мене** — у профілі вашого користувача;
   - **Для всіх користувачів** (Windows) — `C:\ProgramData\FreeMon`, один список для всіх користувачів комп'ютера;
   - **Портабельно** — тека `data` поруч із програмою (флешка);
   - **Своя тека**.
5. **Доступ до змін:**
   - **Без обмежень** — будь-хто змінює список і налаштування;
   - **Режим перегляду, адміністратор за кнопкою** — захист від випадкових змін;
   - **Режим перегляду, адміністратор за паролем** — захист від сторонніх.

Посилання «Що вміє FreeMon» відкриває опис можливостей, «Важливо про шифрування» — короткі правила щодо даних.

## 2. Головне вікно

- **Панель кнопок** (групами):
  - **Пристрій:** Додати · Змінити · Увімк./вимк. · Прибрати;
  - **Дані ▾:** імпорт і експорт списку (CSV), створення резервної копії, відновлення;
  - **Звіти:** Історія та звіти;
  - **Програма:** Налаштування · кнопка режиму (адміністратор / перегляд).
- **Лічильники станів** праворуч угорі: скільки пристроїв на зв'язку, нестабільних, без зв'язку, вимкнених, невідомих.
- **Вкладки «Мапа» і «Дерево»** — два подання того самого списку.
- **«Події»** знизу — журнал змін стану. Згортаються стрілкою; у згорнутому стані остання подія показується в рядку стану.
- **Рядок стану:** у режимі адміністратора — посилання «Тека даних»; завжди — «Про програму».
- **Для стіни:** стрілка ⌃ зліва вгорі згортає все над мапою чи деревом, лишаючи лише лічильники.
  Повторне натискання (⌄) розгортає. Стан запам'ятовується.

## 3. Пристрої

**Додати** — новий пристрій (якщо в дереві чи на мапі вибрано пристрій, він стане батьківським).

- **Назва, адреса** — IPv4, IPv6 або ім'я хоста.
- **Тип** — визначає іконку і параметри пінгу за замовчуванням.
- **Батьківський пристрій** — той, через який цей підключений (роутер, світч). Коли батько недоступний,
  діти показуються як «Недоступний через батька».
- **Група, опис** — довільні, опис видно в підказці.
- **Моніторинг увімкнено** — вимкнений пристрій не перевіряється.
- **Надсилати події в канали** — email і вебхуки для цього пристрою.
- **Відтворювати звуки** — звукові сповіщення для цього пристрою.
- **Як визначати стан:** пінг (за замовчуванням) або — для пристроїв, що не відповідають на пінг, — TCP-порт,
  HTTP(S)-запит чи DNS-запит. Тоді пінг не надсилається взагалі.
- **Параметри пінгу:** порожнє поле — успадкувати від типу або загальних налаштувань.
- **Підключення** — SSH і веб-посилання для меню правого кліку (порт підставляється сам; для веба можна вказати шлях,
  наприклад `settings`).
- **Додаткові перевірки** — TCP-порт, HTTP(S), DNS, HTTP JSON. Мають власні стани й події, на значку пристрою показуються
  кольоровою крапкою. У PDF-звіт не потрапляють, але є в журналі та сирому журналі.
- **HTTP JSON** — GET-запит, з JSON-відповіді за шляхом береться значення й порівнюється з умовами:
  «Є зв'язок, коли…», інакше «Нестабільно, коли…» (необов'язково), інакше «Немає зв'язку». Порівняння: існує, =, ≠, містить,
  <, ≤, >, ≥, між, regex. Шлях: `state`, `attributes.temperature`, `data[0].value`.
  Приклад для Home Assistant: URL `http://<HA>:8123/api/states/sensor.<назва>`, заголовок
  `Authorization: Bearer <довготривалий токен>` (Профіль користувача HA → Безпека → Довготривалі токени), шлях `state`,
  «Є зв'язок, коли значення < 30», «інакше Нестабільно, коли < 40». Кнопка «Перевірити зараз» показує отримане значення.

**Увімк./вимк.** — швидко зупинити або відновити моніторинг. **Прибрати** — видалити зі списку (історія в журналі лишається).

## 4. Стани і параметри

| Стан | Означає |
| --- | --- |
| Є зв'язок | відповіді є, втрати й затримка в межах порогів |
| Нестабільно | є втрати або затримка вища за поріг |
| Немає зв'язку | втрати не менші за поріг «Немає зв'язку» (за замовчуванням — 100 %) |
| Недоступний через батька | пристрій не відповідає, а його батько теж недоступний |
| Вимкнено / Невідомо | моніторинг вимкнено / ще немає результату |

Стан змінюється лише після кількох перевірок поспіль з тим самим новим результатом
(«Перевірок поспіль для зміни стану»). Параметри задаються на трьох рівнях: **загальні**
(«Налаштування → Загальні») → **тип пристрою** («Налаштування → Типи пристроїв») → **пристрій**.
Порожнє поле = успадкувати рівень вище.

## 5. Мапа

- Кожна **родина** — картка: батько в центрі, діти навколо; «Окремі пристрої» — ті, що без батька й без дітей.
- **Кнопки в заголовку картки** (праворуч):
  - **←** — назад (лише у відкритій окремо родині);
  - **⤢** — відкрити лише цю родину;
  - **↺** — повернути позначки родини на місця (режим адміністратора);
  - **▾ / ▸** — згорнути / розгорнути.
- **Навігація:** коли відкрита окрема родина, під панеллю мапи — «‹ Назад · Усі родини › …».
- **Перетягування** (режим адміністратора): позначки — всередині картки; картки — за заголовок.
  **«↺ Розкласти родини автоматично»** прибирає збережені позиції карток.
- **Режими:** усі розгорнуті / лише проблемні / усі згорнуті; галочка «рамки й підписи родин».
- **Початок розкладки** (лівий верхній кут, зверху по центру, по центру) — «Налаштування → Загальні».

## 6. Сповіщення

**«Налаштування → Сповіщення»:**
- **спливаюче вікно** в правому нижньому куті: на які зміни, через скільки секунд закривати;
- **звуки:** для «Немає зв'язку» / «Нестабільно» і окремо тихий звук відновлення; кнопки ▶ — прослухати;
- **головний вимикач каналів** (email, вебхуки).

**«Налаштування → Канали»** — куди надсилати зміни:
- **Email (SMTP)** — сервер, порт, шифрування (STARTTLS / TLS), користувач, пароль, від кого, кому.
- **Вебхук** — шаблони: Telegram, Virola, Node-RED / JSON, ntfy, Gotify, Mattermost / Slack, власний.
  Підстановки: `{text}`, `{device}`, `{address}`, `{from}`, `{to}`, `{status_code}`, `{time}` та інші (перелік — у діалозі каналу).
- **«Надіслати тестове повідомлення»** перевіряє канал одразу.

Зміни, що сталися майже одночасно, надсилаються одним повідомленням; при збої — повторні спроби.
**Увага:** публічні сервіси (Telegram, зовнішня пошта) отримують назви й адреси ваших пристроїв.

## 7. Історія та звіти

**«Історія та звіти»** (або правий клік по пристрою):
1. Виберіть пристрій і період (сьогодні, вчора, 7 / 30 днів, поточний / попередній місяць, довільний).
2. Підсумок звичайною мовою, графік і перелік інцидентів показуються одразу.
3. **PDF-звіт** — з організацією, автором, коментарем, місцем для підпису і кодом перевірки.
4. **Сирий журнал (TXT)** — кожна перевірка, зміни стану, додаткові перевірки, перерви в моніторингу.

**Графік:** лінія — середня затримка, стовпчики — втрати, смуга внизу — стан.
**Заштриховані сірі ділянки — перерви в моніторингу** (FreeMon не працював або моніторинг пристрою було вимкнено).
Такі періоди перелічені у звіті (у таблиці інцидентів і окремим розділом) й не входять у відсоток доступності.
**Масштаб графіка** — лише для перегляду, як шкала часу у відеореєстраторі: коліщатко миші над графіком збільшує
чи зменшує масштаб навколо курсора, перетягування мишею рухає графік уліво-вправо, подвійний клік або «Скинути масштаб»
повертає весь період. Над графіком смужка показує, яку частину періоду видно. Підсумок, інциденти, PDF і TXT завжди
рахуються за весь вибраний період, незалежно від масштабу.
Після збереження PDF чи TXT програма пропонує одразу відкрити файл.

**Перевірити звіт…** — вставте код з PDF (розділ «Автентичність звіту»): програма перерахує показники з журналу
і скаже, чи звіт справжній і чи не змінювались дані.

## 8. Безпека

- **Режим перегляду:** видно стан, журнал і звіти; змінювати список і налаштування та виходити з програми можна лише
  адміністратору. Кнопка режиму — на панелі.
- **Пароль адміністратора** і **автоблокування** — «Налаштування → Безпека». Там само: чи дозволені в режимі перегляду
  «Історія та звіти» і підключення до пристроїв.
- **Зміни поза програмою.** Якщо конфігурацію змінили не через FreeMon, при вході адміністратора буде показано перелік
  змін із можливістю відкату.
- **Шифрування:** конфігурація, секрети каналів і ключ прив'язані до комп'ютера. Деталі — «Про програму → Політика шифрування».

## 9. Персональні налаштування

**«Налаштування → Персональні»** — лише для вас на цьому комп'ютері (у режимі перегляду це єдина доступна вкладка):
- мова інтерфейсу (діє після перезапуску);
- чим відкривати веб-підключення: браузер за замовчуванням або вибраний (з профілем, наприклад `firefox -P Мережа {url}`);
- чим відкривати SSH: термінал системи, обробник `ssh://` або своя команда (наприклад, PuTTY).

## 10. Резервні копії і перенесення

**«Налаштування → Резервні копії»** або **«Дані ▾»**:
- **Створити резервну копію…** — файл `.fmbackup` з паролем: налаштування, списки, секрети каналів, за бажанням — журнал.
- **Автоматичні копії** — щодня або щотижня в задану теку (краще на іншому диску чи мережевому ресурсі). Пароль автоматичних
  копій задається один раз; копії робляться без його введення, а відкрити їх можна лише з ним.
- **Відновити з резервної копії…** — повністю замінює поточні дані (не об'єднує) і перезапускає FreeMon.

**Перенесення на інший комп'ютер:** зробіть копію → встановіть FreeMon на новому комп'ютері → у майстрі
**«Відновити з резервної копії…»**. Просто скопіювати теку даних не можна: вона зашифрована ключем старого комп'ютера.

## 11. Імпорт і експорт CSV

Формат — роздільник `;`, кодування UTF-8, перший рядок — заголовок. Обов'язкові колонки `name` і `address`;
інші: `type`, `parent_address`, `group`, `description`, `enabled` (1/0), параметри пінгу (`interval_s`, `packet_count`,
`packet_interval_ms`, `timeout_ms`, `packet_size`, `down_loss_pct`, `deg_loss_pct`, `deg_avg_ms`, `deg_max_ms`,
`deg_jitter_ms`, `confirm_cycles`). Приклад — `sample-devices.csv`. Імпорт оновлює пристрої з тією самою адресою
і додає нові. Основна і додаткові перевірки та підключення в CSV не переносяться.

## 12. Меню правого кліку

- **Підключення** — налаштовані SSH і веб.
- **Трасування маршруту (MTR)…** — маршрут і втрати на кожному вузлі. Використовує системні утиліти:
  `mtr` (Linux; якщо немає — `tracepath` / `traceroute`), `pathping` / `tracert` (Windows).
  На openSUSE: `sudo zypper install mtr`, Debian / Ubuntu: `sudo apt install mtr-tiny`.
- **Історія та звіти**, **Змінити…** (адміністратор).

## 13. Трей і автозапуск

- Значок у треї показує найгірший стан; підказка — кількість пристроїв за станами.
- Меню: **Відкрити**, **Перезапустити** (адміністратор, з підтвердженням), **Вийти** (у режимі перегляду — з підтвердженням
  або паролем).
- Кнопка «Закрити» вікна ховає програму в трей (налаштовується). Повторний запуск FreeMon відкриває вікно вже запущеної копії.
- **Автозапуск при вході в систему** — «Налаштування → Загальні».

## 14. Поширені питання

- **Пінг на Linux «не працює» без root.** FreeMon використовує ICMP-сокети, дозволені параметром ядра
  `net.ipv4.ping_group_range`; якщо їх немає — системну утиліту `ping`. Режим пінгу видно в «Про програму».
- **Немає звуку.** Перевірте, що звуки увімкнені в «Сповіщеннях» і для пристрою; на Linux потрібен `paplay`, `pw-play` або `aplay`.
- **Windows попереджає про невідомого видавця.** Програма не підписана цифровим підписом: «Докладніше → Все одно запустити».
- **Дані «не розшифровуються».** Теку скопійовано з іншого комп'ютера або перевстановлено ОС — відновіть дані
  з резервної копії через майстер.
- **Журнал займає багато місця.** Термін зберігання — «Налаштування → Загальні» (за замовчуванням 30 днів).
